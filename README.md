# ALCYE CAR

Aplicação web da plataforma ALCYE CAR, incluindo dashboard, garagem virtual, oficina 3D, dinamômetro e fórum de peças.

## Estrutura

- `index.html`: landing page e dashboard principal.
- `pages/`: módulos da aplicação.
- `assets/css/`: estilos compartilhados e estilos específicos de página.
- `assets/js/`: lógica compartilhada e módulos JavaScript.
- `assets/images/`: imagens e logotipo.
- `assets/audio/`: efeitos sonoros.
- `assets/video/`: vídeos da aplicação.

Abra `index.html` em um navegador para iniciar a aplicação. O estúdio 3D e os módulos continuam usando as bibliotecas CDN já existentes.
